# Инструкция менеджера сайта: <Проект>

Памятка владельцу / менеджеру: что менять в админке без разработчика. Адрес админки: `<https://домен/wp-admin/>`. Заполнить под проект на фазе 7 и передать заказчику.

## Компания и контакты

**Компания** (левое меню): название, телефоны (первый — основной), e-mail, адрес, координаты, часы работы, соцсети и мессенджеры, зона обслуживания, ID Google Analytics, запасная картинка. Эти данные сразу попадают в шапку, подвал, страницу контактов, карточку организации для поисковиков и `/llms.txt`. Телефоны в тексты страниц вручную **не** вписывать — иначе при смене номера останутся старые.

## Заявки

**Заявки**: все заявки с сайта; колонки — контакт, источник (страница), статус. Статус меняйте в заявке: «Новая» → «В работе» / «Закрыта» / «Спам». Фильтр по статусу — над списком. Вручную заявки не создаются.

**Заявки → Telegram:** токен бота и ID чата для уведомлений. Токен после сохранения не показывается. Проверка — отправить тестовую заявку с сайта и удалить её. Нет настроек — заявки сохраняются, но уведомления не приходят.

## FAQ

**FAQ → По местам:** вопросы сгруппированы по месту вывода (главная, страница услуги …). Внутри группы — перетаскивание для порядка, правка, удаление; дождитесь окончания загрузки. Новый вопрос — «Добавить», поля «Место вывода» и «Порядок». Ответ должен совпадать с тем, что видно на сайте (он же уходит в разметку для поисковиков).

## Отзывы, портфолио, карточки услуг

- **Отзывы / Портфолио** — обычные записи; порядок — «Атрибуты → Порядок» (меньше — выше). У фото задайте **alt** (что изображено).
- **Карточка услуги** — в редактировании страницы услуги, блок «Карточка услуги»: заголовок, текст, цена-строка, бейдж, порядок, картинка. Цена здесь — текст для показа; меняется вручную.

## Меню

**Внешний вид → Меню:** области «Главное меню» (шапка), «Мобильное меню», «Меню в подвале». Пустое или неназначенное меню — сайт покажет автоматический список страниц. Служебные страницы в клиентское меню не добавлять.

## Блог

**Записи:** у каждой записи — изображение записи (обложка), рубрика, заголовки H2 / H3 (оглавление строится само для длинных статей). Title и description — блок Yoast под редактором.

## SEO

Title / description страниц — блок **Yoast SEO** в редактировании. Второй разметки schema вручную не добавлять.

## Начальные данные (для разработчика)

Демо / первичное наполнение: **Инструменты → Starter Seed** (после `npm run init` — «<Name> Seed») или `npm run wp -- starter seed`. Повторный запуск не создаёт дублей и не трогает текст страниц. После запуска сайта менеджер правит данные в админке, seed больше не нужен.

## Не делать

- Устанавливать / удалять плагины и менять тему.
- Менять адрес страниц (slug) без разработчика — сломаются ссылки и меню.
- Вставлять в текст телефоны, скрипты счётчиков, iframe карт.
