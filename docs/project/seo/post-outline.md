Копировать на пост в `seo/posts/<slug>.md`. Шаблоны блога — [`contracts/blog.md`](../../contracts/blog.md).

## Outline

| Поле | Значение |

1. Lede (3–5 предложений): конфликт / путаница / цена ошибки — не определение из учебника.

4. FAQ (не копия FAQ коммерческих страниц).
5. Развилка «когда звонить» → коммерческая страница.

## Правила текста (обязательно при AI-генерации)

- Голос практика: короткие предложения, бытовая лексика, конкретика с единицами; «однозначного ответа нет» допустимо. «Вы» — читателю, «мы» — только в развилке.
- 800–1400 слов, не раздувать; абзац: факт → зачем / что будет, если нарушить.
- **Запрещено:** «в современном мире», «в этой статье мы расскажем», «важно отметить», «комплексный подход», «оптимальное решение», «давайте разберёмся», «подводя итоги»; стопки риторических вопросов; эмодзи; целевая фраза в каждом абзаце; выдуманные нормы, цены, исследования и кейсы с именами.
- **Запрещённые структуры:** lede «X — это важный элемент…»; «плюсы и минусы» без критериев; повтор H1 в первом абзаце; заключение-пересказ; одинаковые по длине секции; списки ради списков.
- **Обязательно в каждом посте:** один практический якорь (условия региона / участка), одна цена ошибки, одно честное ограничение, одна развилка «когда звонить»; цифры — только проверяемые по сайту.
- Целевая фраза — не чаще 2–3 раз в теле (H1 не считается).

## Чеклист редактуры

- [ ] Lede понятен за 15 секунд вслух
- [ ] Нет фраз из списка запретов
- [ ] Нет выдуманных норм / цен / «исследований»
- [ ] Нет раздела «Итоги / Заключение»
- [ ] Не копирует соседние посты и FAQ дословно
- [ ] Абзац нельзя вставить в любую статью по теме без правки
- [ ] Обложка задана; ≥ 2 H2 для оглавления
