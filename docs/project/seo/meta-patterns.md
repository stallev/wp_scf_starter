## Правила синхронизации

- Домен меняется везде одним проходом (canonical, OG, JSON-LD, `robots.txt`, sitemap, `llms.txt`) — в WordPress это делает смена «Адреса сайта», литералов домена в коде нет.
- `og:title` / `og:description` — синхронно с title / description (Yoast по умолчанию).
- `name` / `description` в схемах берутся из данных сайта; осознанное расхождение с meta фиксируется здесь с причиной.
