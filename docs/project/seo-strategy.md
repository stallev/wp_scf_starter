## 2. Конкурентная карта

<Кто в топе по широким и по гео-запросам (агрегаторы, классифайды, сайты компаний); где порог входа низкий. Источники — фактическая выдача, не предположения; оговорки о полноте выборки.>

## 3. Приоритизация (Парето)

<2–3 страницы дают 80 % результата: они получают больше контента и внутренних ссылок. Остальные — достаточные шаблоны.>

## 4. Реализация в WordPress

- Schema по типу страницы → поле `schema` в `pages-map.json` (LocalBusiness — сайт целиком; Service — услуги; FAQPage — страницы с видимым FAQ).
- `areaServed`, адрес и geo — опции «Компания» (фильтр `starter_schema_area_served`).
- Title / description — Yoast, по [`seo/meta-patterns.md`](seo/meta-patterns.md).

## 5. Локальное SEO вне сайта

Google Business Profile / Яндекс Бизнес — заполнить параллельно с разработкой, NAP = опции «Компания». Эффект — недели, быстрее индексации новых страниц.
