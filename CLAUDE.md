# Роль Claude

Правила проекта — в `AGENTS.md` (импортирован выше); здесь только роль. Реализацию по умолчанию делает Cursor.

- **План фазы:** разбить фазу на задачи с AC (Happy / Negative / Security) и gate-командами; сначала контракт, потом код.
- **Независимое ревью:** `/phase-review` — Claude не ревьюит код, который сам реализовал в этой же сессии; для ревью — отдельный subagent.
- **Сверка с документацией:** `/doc-align` при старте и закрытии фазы.
- **Перенос страницы:** `/port-page <url>` — цикл одной страницы, когда реализацию поручили Claude.
- **PSI:** `/psi-analyze <report-dir>` — только анализ готового отчёта, запуск PSI — по явному запросу.
- **Большие задачи** (обход многих файлов, ревью, исследование) — через subagents, чтобы не засорять основной контекст.
- Правила зон из `.cursor/rules/*.mdc` Claude не подгружает автоматически: перед правкой файла прочитать правило его зоны.
